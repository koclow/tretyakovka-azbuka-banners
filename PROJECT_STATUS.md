## Проверено и отброшено
- Заливка гигабайта на Яндекс.Диск скриптом с аймака — 150 КБ/с и обрывы (маршрут через роутер
  и туннель), до Maura при этом 6 МБ/с. Крупные файлы проще залить руками из браузера или через
  Maura как перевалку; скрипт оставлен для мелких файлов и публикации ссылки.
- Тексты L-board из PNG @2x — на финальном MOV края мягкие (Никита: «видны пиксели, особенно
  плашка»). Переведены на SVG в сцене (три строки — clipPath), иллюстрации на PNG @4x, финал рендерится
  с суперсэмплингом 2× (`SS=2`, даунскейл Lanczos). Больше из 1080p не выжать — это предел ТТ.
- Нейровидео Kling 3.0 (image-to-video, first_image, 14 с, 1080p) — две попытки, 4 генерации,
  448 кредитов. Вся полоса целиком: значки крутятся как монеты, фон шумит. По одному значку
  в квадрате с сюжетными промптами («конь перебирает ногами», «свет на горах меняется»,
  «пара чуть ближе»): сюжеты ожили, но модель перерисовывает графику в свою манеру (у всадника
  другое лицо и волосы, значок деформируется, у круга глянцевый 3D-ободок), фон с текстурой.
  Никита: «видосы не подходят». Ключевание фона по RGB работало чисто, но не понадобилось.
  Файлы `lboard/dist/kling_*_14s.mp4` оставлены для справки.
- PNG-экспорт Figma (`download_assets`) всегда с подложкой — фон фрейма или серый канвы, даже
  из фрейма без заливки. Для слоёв с альфой брать SVG-экспорт и растеризовать самим; у SVG
  из Figma тоже два фоновых `<rect>` в начале — вырезать.
- Маска `mask-image: url(...)` из `file://` в headless Chrome блокируется CORS — флаг
  `--allow-file-access-from-files` в рендере.
- Скриншот puppeteer с `clip` при остановленных анимациях (`?at=`) отдаёт один и тот же кадр
  при любом времени — снимать без `clip`, вьюпорт ровно под размер креатива.
- SVG в архиве — ТТ РБК: «не поддерживаются svg и json». Отрисованы в PNG headless-Chrome.
- Подпапка `assets/` в архиве — ТТ: «без дополнительных папок внутри». Файлы рядом с html.
- Пути с `300x250` / папка `banners/` — блокировщик в Chrome Никиты подменял картинки на 1×1
  (fetch → 500 без заголовков GitHub, curl с той же машины → 200). Переименовано.
- Старт по IntersectionObserver + таймер 1,5 с при видимых слоях — кадр мелькал и исчезал
  («дёрганая первая загрузка»). Слои спрятаны до `play`, старт по `load` и видимости.
- «Смаз» 16 px / scaleX 1.08 / blur 7 px — слишком акцентно по оценке Никиты; теперь 10 / 1.03 / 4.
- Мобильный 300×250 по макету «4» (фото сверху) — заменён новым макетом «iPhone 16».
- Появление заголовка маской слева направо (`clip-path`) — Никита: «как PowerPoint».
  Заменено на пословный «смаз» в языке фирменного ролика.
- Резиновый мобильный 100%×250 с фото во всю ширину — ТТ просит файл 300×250; поля в
  слоте заливает сам РБК. Заменён фиксированным 300×250.
- Headless Chrome для скриншотов: `--virtual-time-budget` с бесконечными CSS-анимациями
  виснет; окно уже 500 px даёт вьюпорт шире экрана (баннер уезжает вправо) — снимать
  окном ≥ 500 и вырезать.
- Раскладка «только набор» сразу ниже 680 px — на планшете 680 слот РБК-страницы
  получается 664–678 px, и билборд проваливался в мобильный вид. От 600 до 679 теперь
  макет 680 по центру с подрезкой.
- Кэш CDN GitHub Pages (10 минут на URL) отдавал старые креативы в схеме страницы —
  рамка пробрасывает версию в адреса креативов.
- `%` в формулах интерполяции (`calc(100% - 680px)`) — в `top` проценты считаются от
  высоты контейнера, конь уезжал на 44 px вниз. Заменено на `100cqw`.
- Заголовок, растущий линейно от 680 — к 800 px упирался в голову коня. Растёт с 960 px.
- SVG иллюстрации из Figma (конь 136 КБ, круг 112, пара 100) — втрое тяжелее лимита,
  оставлены PNG @3x в палитре.
- Старт билборда только по IntersectionObserver — в фоновой вкладке Chrome не крутит
  рендеринг, наблюдатель и scroll молчат, слот оставался пустым. Теперь ещё
  visibilitychange + таймер 1,5 с (креатив вставляет сам слот РБК, когда пора), а на
  схеме страницы второй слот опрашивается таймером. Проверено в фоновой вкладке.
- Живые примеры баннеров на rbc.ru снять не удалось: и во встроенном браузере, и в
  Chrome Никиты слоты пустые (0×0, блокировщик). Официальные ТТ и медиакит —
  на rbc.group/advertisers («Технические требования ZIP», «Смотреть медиакит»).
- Живой текст ближайшим гугл-шрифтом — набор расходится с макетом.
- Блик-«шайн» раз в 9 с и построчное покачивание набора — убраны по аудиту анимации.
- Резиновый режим у 680×250 (`?mode=fluid`) — заменён отдельным билбордом, который
  делает то же самое и вдобавок умеет мобильную раскладку.
- Пропорциональное сжатие настольной композиции на мобильном слоте 100%×250 — при
  375 px даёт высоту 138 px и нечитаемый кегль. Вместо этого квадратная раскладка.
- `padding` на контентной коробке для «дышащих» полей — у абсолютных детей
  containing block это padding box, отступ на них не действует.
- CSS-транзишен ширины стенда — анимировать layout плохо, и `transitionend`
  не приходил в связке с `resize:horizontal`.
- Figma MCP: `get_metadata` по узлам обоих файлов падает (SSE обрывается).
  Работали через `get_screenshot` + `download_assets` @3x и разбор по связным компонентам.
- Приватный репозиторий + Pages — план аккаунта не поддерживает.
- Figma loadFontAsync для AzbukaVkusa Regular недоступен. Для композиционных правок клонировать исходник и сохранять фирменные текстовые слои без изменения; замена шрифта не нужна.
