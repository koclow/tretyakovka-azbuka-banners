# Баннеры Третьяковка × Азбука вкуса

HTML-баннеры для размещения на РБК по макетам Никиты: два билборда 100%×250
(первый экран и по доскролу), два мобильных 300×250 (женщина, мужчина), запасной
300×250 сплошным набором. Витрина на тёмном фоне и схема страницы РБК —
через GitHub Pages.

* Живая страница — <https://koclow.github.io/tretyakovka-azbuka-banners/>
* Показ заказчику — <https://koclow.github.io/tretyakovka-azbuka-banners/demo/rbc.html>
* Репозиторий — <https://github.com/koclow/tretyakovka-azbuka-banners> (публичный: Pages на бесплатном плане иначе не работает)
* Макеты — <https://www.figma.com/design/MuQyOuxDwWEzAb28gpTgQC/?node-id=1-2>

## Что где

| Путь | Что |
|---|---|
| `index.html` | витрина: все баннеры, стенд ресайза, таблица слотов, проверка по ТТ |
| `demo/rbc.html`, `demo/page.html` | схема страницы РБК с настоящими названиями слотов |
| `creatives/desktop-illustration/` | перетяжка, иллюстрация (первый экран) |
| `creatives/desktop-photo/` | перетяжка, фото (по доскролу) |
| `creatives/mobile-woman/`, `mobile-man/` | мобильные 300×250, тянутся по слоту |
| `creatives/square-plain/` | запасной 300×250 из первого макета |
| `fallback/` | заглушки jpg |
| `dist/` | архивы и одиночные файлы для сдачи |
| `build-standalone.py` | сборка `dist/` |
| `README.md` | как устроено: геометрия, анимация, ТТ |
| `lboard/` | L-board для эфира РБК: разбор ТТ, шаблон зон, рендер в ProRes |
| `ТТ РБК/` | официальные ТТ РБК (интернет и телеканал), вне git |

## Как работать

Папка — сама себе git-репозиторий, `origin` = GitHub. Правки в `main` уезжают
на Pages автоматически, минута-две на сборку; CDN кэширует каждый адрес ~10 минут.
После правки баннера пересобрать `dist/`: `python3 build-standalone.py`.
Скриншоты и заглушки снимаются headless-Chrome с `?static`, раскадровка — с `?at=<мс>`;
узкие кадры — через обёртку с iframe (окно Chrome не бывает уже 500 px).
В путях и классах не должно быть `banner`, `300x250`, `100x250` — блокировщики режут.

Состояние — `PROJECT_STATUS.md`, решения — `DECISIONS.md`, хронология — `ЖУРНАЛ.md`.
