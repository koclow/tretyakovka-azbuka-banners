# DECISIONS — Баннеры Третьяковка × Азбука вкуса

## 03.09.2026 (поздно) — пути и классы без рекламных маркеров
В Chrome Никиты блокировщик подменял картинки по пути `…/mobile-300x250-…/assets/…` на
1×1 пиксель (fetch — 500 без заголовков GitHub, curl с той же машины — 200). Папка
`banners/` → `creatives/`, имена без размеров, корневой класс `.cr`. У заказчика может
стоять то же самое — демо не должно зависеть от этого.

## 03.09.2026 (поздно) — мобильный: 300×250 по макету «iPhone 16», тянется по слоту
Никита нарисовал мобильный заново (фото слева, набор справа) и просит адаптив. ТТ допускает
растяжение («если креатив не растягивается на 100 %…»). Файл на 300 px — ровно 300×250,
шире — тянется. Высота приведена к 250 сжатием зазора между заголовком и логотипом.

## 03.09.2026 (поздно) — старт анимации: слои спрятаны до старта, старт по load и видимости
Первая загрузка «дёргалась»: кадр показывался целиком, исчезал и появлялся заново — слои
были видны до класса `play`, а старт ждал IntersectionObserver и таймер 1,5 с. Теперь слои
спрятаны с первого кадра, старт по `load` при видимой вкладке, `done` через 3 с фиксирует
финал. IntersectionObserver убран: слот РБК вставляет креатив, когда пора.

## 03.09.2026 — мобильный креатив: файл 300×250 (отменено тем же вечером, см. выше)
ТТ РБК: «Мобильный баннер 300×250 — файл html5», слот 100%×250, поля заливаются
фоновым цветом баннера. Резиновая версия с фото во всю ширину была заменена на
фиксированный 300×250 по макету «4». Отменено: Никита нарисовал новый адаптивный макет.

## 03.09.2026 — раскладка креативов по слотам фиксирована
Десктоп: сверху иллюстрация (А), по доскролу фото (Б). Мобильный: сверху женщина,
по доскролу мужчина. Переключатели в демо убраны — заказчику показываем одну
договорённость, а не конструктор. Решение Никиты.

## 03.09.2026 — появление текста: слово за словом со «смазом», не маска
Маска слева направо (`clip-path`) выглядела как переход из PowerPoint. Взят язык
фирменного ролика Третьяковки × Азбуки вкуса: элементы въезжают слева с горизонтальным
размытием, по одному. Направленного размытия в CSS нет — эмулируется `blur()` +
`scaleX(1.08)` + сдвиг; SVG-фильтр с `feGaussianBlur` по одной оси отброшен ради
надёжности в рекламных сетях и простоты повтора по клику.

## 03.09.2026 — L-board не делаем в рамках этой работы
В ТТ выделен ещё L-board — видео MOV ProRes 4444 1920×1080 для эфира телеканала.
Это другой продукт (монтаж, а не HTML); в задаче не подтверждён — ждём Никиту.
